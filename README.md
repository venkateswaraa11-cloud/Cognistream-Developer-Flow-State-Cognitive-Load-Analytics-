# Cognistream
### Developer Flow State & Cognitive Load Analytics

## Project Overview
Cognistream is a data analytics project designed to explore developer workflow patterns, focus periods, task switching, and potential indicators of cognitive load using developer activity data.

## Objectives
- Analyze developer activity and workflow patterns.
- Explore focus sessions and interruptions.
- Identify task-switching patterns and potential cognitive-load indicators.
- Build data-driven visualizations and dashboards.
- Communicate findings through analytical reports.

## Technology Stack
- **Programming:** Python
- **Workflow Orchestration:** Apache Airflow
- **Data Processing:** Polars
- **Database:** ClickHouse
- **Query Language:** SQL
- **Backend API:** FastAPI
- **Frontend:** React
- **Dashboard Visualization:** Tremor.js
- **Version Control:** Git and GitHub
## Project Status
Initial setup - dataset selection, data preparation, and analysis are upcoming.

## Expected Outcome
An analytics workflow and interactive dashboard that summarize developer workflow patterns and support further investigation of focus and cognitive load.

## Important Note
Developer activity metrics are indirect indicators. They cannot independently measure a person's actual cognitive load or prove that someone is in a flow state.
